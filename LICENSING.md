# Licensing

Control Tower is **open source**, licensed under the **GNU Affero General Public
License, version 3** ([`LICENSE`](./LICENSE)). This page is a plain-language summary
for convenience — the binding terms are in `LICENSE`.

## The short version

| You want to… | Allowed under the AGPL? |
| --- | --- |
| Install Control Tower and run your own project or company with it | **Yes** |
| Read, modify, fork, and self-host it | **Yes** |
| Write your own plugins and agents for your own install | **Yes** |
| Redistribute it, modified or not | **Yes**, under the AGPL, with the source |
| Run a **modified** Control Tower as a service other people use over a network | **Yes — but** you must offer those users the complete source of your modified version (AGPL §13) |
| Embed Control Tower inside a **closed-source** product, or sell it as a hosted service **without** publishing your changes | **Not under the AGPL** — needs a commercial license |
| Remove or hide the license or copyright notices | **No** |

If you are unsure whether the AGPL works for you: **support@dee-empire.com**.

## The commercial license

Dee Empire offers a **commercial license** with the same code under terms that drop
the AGPL's network-source requirement, for:

- embedding Control Tower in a closed-source product;
- running a modified Control Tower as a hosted or managed service for others
  without publishing the modifications;
- organisations whose procurement or legal policy blocks AGPL software outright.

**support@dee-empire.com** for terms.

## Why AGPL

Control Tower is meant to be installed by founders on their own servers. The AGPL
keeps it genuinely open source (OSI-approved, no limits on running it, including for
your own business) while making one thing — running a *closed* modified version as a
service for others — require either publishing those changes or a commercial license.

## Contributions

Contributions are welcome, under a [Contributor License Agreement](./CLA.md). It
keeps your copyright with you while letting the project offer Control Tower under
both the AGPL and a commercial license. You accept it by signing off your commits
(`git commit -s` adds a `Signed-off-by` line) and confirming when prompted on your
first pull request.
