## What it is for

One look to see whether everything runs. It refreshes every 30 seconds.

## What you see

| Number | Meaning |
|---|---|
| **Agents** | How many agents the team has, and how many are switched on. |
| **Runs today** | Agent runs since midnight. |
| **Waiting for your clearance** | Proposals in [Clearance](docs:approvals). |
| **Failed tasks (24 h)** | Background tasks that failed, with how many gave up (dead) and how many wait. See [Task queue](docs:tasks). |
| **AI spend today / this month** | Against the install's caps; orange from 80 %. See [AI usage](docs:usage). |

**Background work** shows when the last task finished and how many are queued.

When an emergency switch is on (see [Platform](docs:platform)), a warning at the top says so.
